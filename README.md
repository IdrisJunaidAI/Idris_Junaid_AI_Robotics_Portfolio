## 6. Final Capstone Project

### Human Temperature Detection Using PiDog

**Project Type:** Collaborative Robotics Capstone

**Portfolio Type:** Individual Academic Documentation

The final capstone project investigates the
modification of the SunFounder PiDog robotic
platform to support human temperature detection.

The project explores the integration of temperature
sensing hardware, embedded computing, data processing,
robotic interaction, and temperature reporting.

The intended outcome is an educational robotics
prototype capable of acquiring and processing
temperature measurements under defined
experimental conditions.

This individual portfolio documents my specific
contributions, technical responsibilities,
engineering decisions, testing activities,
observations, and lessons learned.

The prototype is intended for educational research
and is not a clinically validated medical device.

[View Final Capstone](05_Final_Capstone/Human_Temperature_Detection_PiDog/)
