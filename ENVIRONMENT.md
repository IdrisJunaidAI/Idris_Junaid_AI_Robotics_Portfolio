# Runtime environment and reproducibility

## Host simulation
Python 3; no third-party packages. From the repository root run:

```sh
python3 03_Laboratory_Experiments/LAB01_Hardware_Software_Introduction/code/pwm_model.py
python3 03_Laboratory_Experiments/LAB01_Hardware_Software_Introduction/code/behavior_example.py
```

## Hardware exercises
The documented classroom setup used Raspberry Pi 5, PiDog V2-compatible hardware, Robot HAT and Raspberry Pi OS. Lab 9 records Debian 13, Python 3.13.5, Robot HAT 2.5.8, PiDog 1.4.0 and Vilib 0.3.20 at setup. These are historical observations, not a tested lockfile.

Follow [official PiDog setup and examples](https://docs.sunfounder.com/projects/pidog/en/latest/) for revision-specific installation and calibration. [Manufacturer source](https://github.com/sunfounder/pidog). Confirm installed API and hardware revision. Use a supervised, calibrated robot in a cleared test area; software stop is not a physical emergency stop. Do not run Lab 3/4 scripts on a desktop or uncalibrated robot. Original report listings were proposed and not hardware validated. Source versions for other labs were not supplied; do not represent manufacturer code as original student code.
